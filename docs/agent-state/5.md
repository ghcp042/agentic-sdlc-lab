# Issue 5: Allow returns within 30 days of delivery

## Implemented

- Added `RETURNED` as an order status.
- Allowed `DELIVERED -> RETURNED`; `RETURNED` is terminal.
- Added unit coverage for the valid return transition and terminal behavior.

## Open questions

- The issue specifies a 30-day return window, but orders do not currently record a delivery date. What date source should define the start of that window? The transition cannot enforce the 30-day limit until that is decided and modeled.

## Follow-up

- Add a database migration for the new `RETURNED` enum value. No migration is included in this change.
